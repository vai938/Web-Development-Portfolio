# Web Development Portfolio

Welcome to my Web Development showcase! This repository serves as an organized index of web applications, full-stack builds, and interactive tools I have created. 

My background in web development provides a strong foundation for building intuitive user interfaces, handling API integrations, and managing end-to-end data pipelines.

---

## 🛠 Tech Stack

* **Front-End:** HTML5, CSS3, JavaScript, React.js, Tailwind CSS, Bootstrap
* **Back-End:** Node.js, Express.js
* **Databases:** MongoDB
* **Tools & Deployment:** Git/GitHub, REST APIs, Postman, Vercel/Render

## 🚀 Featured Web Projects

### 1. [Student Teacher Booking App](https://github.com/vai938/student_teacher_booking)
* **Description:** A scheduling interface designed to connect students with instructors for booking academic sessions and managing appointments.
* **Tech Stack:** HTML, CSS, JavaScript
* **Key Features:** Session scheduling logic, booking status management, and clean user layout.

---

### 2. [Bankist Login System](https://github.com/vai938/bankist_login_system)
* **Description:** An interactive banking application interface featuring simulated user authentication, transaction history, and account transfers.
* **Tech Stack:** JavaScript (ES6+), HTML5, CSS3
* **Key Features:** Authentication flow (Demo credentials: `vt` / `1111`), dynamic DOM manipulation, real-time balance calculations, and timer-based auto-logout.

---

### 3. [Super Mall Web App](https://github.com/vai938/super_mall_webapp)
* **Description:** A dynamic e-commerce style web interface for managing and displaying commercial products and services.
* **Tech Stack:** JavaScript, HTML, CSS
* **Key Features:** Product catalog navigation, dynamic rendering, and responsive UI layout.

---

### 4. [Natours Web App](https://github.com/vai938/app_natour)
* **Description:** A modern landing page and application concept for outdoor tour bookings with visual design components.
* **Tech Stack:** JavaScript, Advanced CSS, HTML
* **Key Features:** Custom CSS animations, responsive design breakpoints, and interactive tour cards.

---

### 5. [Forkify Recipe Application](https://github.com/vai938/Forkify)
* **Description:** A recipe search and management web application that fetches data from an external API to display ingredient breakdowns and cooking instructions.
* **Tech Stack:** JavaScript (Async/Await), REST API, HTML/CSS
* **Key Features:** External API integration, recipe bookmarking, dynamic serving size calculations, and search filtering.

---

### 6. [Interactive Map App](https://github.com/vai938/interactive_map)
* **Description:** A location-based web application that allows users to map out specific workouts or events tied to geographic coordinates.
* **Tech Stack:** JavaScript, Geolocation API, Leaflet.js / Map APIs, HTML/CSS
* **Key Features:** Browser geolocation tracking, interactive map marker placement, and event logging by geographic area.
