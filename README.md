## 🚀 Featured Projects

### 1. 🔬 Virtual Labs – ANDC
- **Repository:** [vai938/Virtual_Labs_ANDC](https://github.com/vai938/Virtual_Labs_ANDC)
- **Tech Stack:** `HTML5`, `CSS3`, `JavaScript (ES6+)`, `Canvas API`, `Anime.js`
- **Overview:** An interactive, cross-disciplinary virtual laboratory platform providing real-time interactive simulations for computational physics, numerical analysis methods (Monte Carlo $\pi$ estimation, Bisection method, Newton-Raphson method), and biological experimental workflows (DNA extraction).
- **Highlights:**
  - Real-time client-side numerical computation and graphical canvas rendering.
  - Interactive parameter controls with immediate visual feedback and convergence tracking.
  - Modular, zero-dependency browser architecture designed for educational accessibility.
